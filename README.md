# FastTurbo media

Public screenshot for the FastTurbo Python package on PyPI.

![FastTurbo on macOS after 5,000 iterations](macos-5000-iterations.png)

Captured on Apple M1 Max after exactly 5,000 iterations, with a 2048 × 2048
simulation grid, a 3072 × 3072 padded workspace, and the native Metal / VkFFT
backend. Captured from FastTurbo 0.1.1 with k₀=10, seed 2 and Palinstrophy
regulation off. The screenshot shows vorticity with the Ember palette.
